# Guia de Boas Práticas - InovaWeb
Autor: Murillo dos Santos Pereira

**Sobre o guia**

Este guia apresenta boas práticas de desenvolvimento de software, abordando organização de código, versionamento com Git e GitHub, padronização, documentação e colaboração em projetos. Seu objetivo é incentivar a criação de códigos mais organizados, legíveis e de fácil manutenção.
