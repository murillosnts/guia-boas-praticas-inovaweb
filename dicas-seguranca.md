1. Utilize senhas fortes: Crie senhas longas, com letras maiúsculas e minúsculas, números e símbolos. Evite informações pessoais, como datas de nascimento.

2. Não reutilize senhas: Tenha uma senha diferente para cada conta, evitando que o vazamento de uma comprometa as demais.

3. Verifique os links antes de clicar: Desconfie de links suspeitos recebidos por e-mail, mensagens ou redes sociais. Confira se o endereço do site é legítimo.

4. Mantenha seus dispositivos atualizados: Atualize o sistema operacional, os navegadores e os aplicativos para corrigir falhas de segurança e reduzir riscos de ataques.
